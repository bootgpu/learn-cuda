写一个 GPU 程序，把 `n` 个摄氏温度换算成华氏温度。输入和输出都是 32 位浮点数，每个线程换算一个元素：

```
fahrenheit[i] = celsius[i] * 9 / 5 + 32
```

## 实现要求

- 不允许使用外部库
- 补全 `celsiusToFahrenheitKernel`；给定的 `solve` 已经会启动它
- `solve` 函数的签名必须保持不变
- 最终结果必须存放在 `fahrenheit` 中
- 不得修改输入，也不得读写给定数组范围以外的内存

## 示例 1：

```
输入：celsius = [0.0, 100.0, -40.0, 37.0]
输出：fahrenheit = [32.0, 212.0, -40.0, 98.6]
```

## 示例 2：

```
输入：celsius = [20.0, 25.5, -10.0]
输出：fahrenheit = [68.0, 77.9, 14.0]
```

## 约束

- 1 ≤ `n` ≤ 10,000
- `celsius` 和 `fahrenheit` 各含 `n` 个连续的 32 位浮点数，位于 GPU 显存
- -100 ≤ `celsius[i]` ≤ 100
