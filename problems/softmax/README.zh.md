给定 `N` 个 float 组成的数组 `x`，计算它的 softmax，写进 `y`：

```
m    = max_j x[j]
y[i] = exp(x[i] - m) / sum_j exp(x[j] - m)
```

减去最大值 `m` 不改变结果，但能在 `x` 里有很大的值时防止 `exp` 溢出。

## 要求

- 在 `solution.cu` 里实现 `solve(const float* x, float* y, int N)`，签名和 `extern "C"` 保持初始代码的样子。
- `x` 和 `y` 已经指向 GPU 显存；进入 `solve` 时 `y` 里的内容是未定义的。
- `m` 和分母都取决于整个 `x`，一次 kernel 启动做不完：在 `solve` 里启动多次（例如先求最大值，再求和，最后做除法）。需要的临时显存在 `solve` 里用 `cudaMalloc` 分配。

## 示例

```
输入：x = [1.0, 2.0, 3.0], N = 3
输出：y = [0.0900, 0.2447, 0.6652]
```

```
输入：x = [1000.0, 1000.0], N = 2
输出：y = [0.5, 0.5]
```

## 约束

- 1 ≤ N ≤ 10,000
- -100 ≤ x[i] ≤ 100
- 输出与期望值之差不超过 1e-9 + 1e-4 × |期望值| 即判对
