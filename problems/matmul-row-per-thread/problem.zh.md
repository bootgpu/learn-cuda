写一个 GPU 程序，算出两个 `n` × `n` 方阵的乘积 P = M × N，结果存入 `P`。`M`、`N`、`P` 都按行优先存储。
P 第 row 行第 col 列的元素，是 M 的第 row 行与 N 的第 col 列逐个相乘再相加：

```
P[row][col] = M[row][0] × N[0][col]
            + M[row][1] × N[1][col]
            + …
            + M[row][n - 1] × N[n - 1][col]
```

所有数都是 32 位浮点数。

`solve` 是固定的（见 `harness.cu`）：一共启动 `n` 个一维的线程，每个 block 32 个，grid 向上取整。
每个线程算 P 的一整行：第 row 个线程（从 0 数起）算出第 row 行的全部 `n` 个元素。

## 实现要求

- 不允许使用外部库
- 补全 `matMulRowKernel`，名字和参数保持不变
- 不要写 `solve`，判题时会提供
- 最终结果必须存放在 `P` 中
- 不得修改输入，也不得读写给定数组范围以外的内存

## 示例 1：

```
输入：n = 2
      M = [[1.0, 2.0],
           [3.0, 4.0]]
      N = [[2.0, 0.0],
           [1.0, 3.0]]
输出：P = [[ 4.0,  6.0],
           [10.0, 12.0]]
```

## 示例 2：

```
输入：n = 3
      M = [[1.0, 2.0, 0.0],
           [0.0, 1.0, 1.0],
           [2.0, 0.0, 1.0]]
      N = [[1.0, 0.0, 1.0],
           [0.0, 2.0, 0.0],
           [1.0, 1.0, 0.0]]
输出：P = [[1.0, 4.0, 1.0],
           [1.0, 3.0, 0.0],
           [3.0, 1.0, 2.0]]
```

## 约束

- 1 ≤ `n` ≤ 100
- `M`、`N`、`P` 各含 `n` × `n` 个连续的 32 位浮点数，都位于 GPU 显存
- −10 ≤ `M`、`N` 的元素 ≤ 10
