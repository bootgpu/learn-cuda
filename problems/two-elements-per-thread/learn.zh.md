本关在一种新的启动方式下，练 PMPP 第 2 章的下标公式。

一个线程算一个元素时，公式的意思是「前面的 block 占掉的位置，加上我在自己 block 里的位置」：

```cpp
int i = blockIdx.x * blockDim.x + threadIdx.x;
```

换成本关的启动方式，把这两个问题重新问一遍：每个线程管两个元素了，前面每个 block 占掉多少
个位置？一个线程的那两个元素，在自己 block 里从哪儿开始？线程算出第一个元素之后，第二个元素
要单独跟 `n` 比一次：`n` 是奇数时，最后一个线程只有一个元素要算。

取相邻的两个元素不是唯一的分法。也可以让一个线程取数组前半段的一个、后半段的一个。两种写法
本关都能过；第 6 章讲合并访存时，再比较它们在速度上的差别。
