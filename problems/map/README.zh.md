给定 `N` 个 float 组成的数组 `x`，写一个 kernel，对每个 `i` 计算

```
y[i] = 2 * x[i] + 1
```

每个线程负责一个元素。

## 要求

- 在 `solution.cu` 里实现 `solve(const float* x, float* y, int N)`，签名和 `extern "C"` 保持初始代码的样子。
- `x` 和 `y` 已经指向 GPU 显存，在 `solve` 里启动你的 kernel。
- 结果写进 `y`；进入 `solve` 时 `y` 里的内容是未定义的。

## 示例

```
输入：x = [1.0, 2.0, 3.0, 4.0], N = 4
输出：y = [3.0, 5.0, 7.0, 9.0]
```

```
输入：x = [-0.5, 0.0, 10.0], N = 3
输出：y = [0.0, 1.0, 21.0]
```

## 约束

- 1 ≤ N ≤ 1024，一个 block、`N` 个线程就够
- -100 ≤ x[i] ≤ 100
- 输出与期望值之差不超过 1e-5 + 1e-5 × |期望值| 即判对
